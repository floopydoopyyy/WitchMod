RITUAL TABLE — editable textures (all 16x16 PNG, RGBA)
======================================================
(In-game name: "Ritual Table". The registry id + asset filenames stay `bewitching_table`
so saved worlds, blockstates, recipes and loot tables are untouched.)

Model: models/block/bewitching_table.json. Shape, bottom to top:
  - a PURPLE foot layer            (14x14, y 0..1)   <- the ornate bottom pixel-row
  - a stepped POLISHED BLACKSTONE plinth (12x12, y 1..3)
  - a flared column FOOT collar    (10x10, y 3..4)
  - a slender column SHAFT         ( 6x6 , y 4..10)
  - a flared column CAPITAL        (10x10, y 10..11)
  - a full 16x16 TOP SLAB overhang (y 11..16)
  - the top FACE = one carpet tile with 4 flat purple corner squares
  - carpet FLAPS drape over the middle of each of the 4 sides

Every model face is mapped 1:1 (1 texture pixel = 1 model pixel), so it stays a
true Minecraft 16x16 look — no squashed/dense areas. Paint each tile as a normal
16x16 and F3+T (resource reload) to see it, no rebuild needed.
