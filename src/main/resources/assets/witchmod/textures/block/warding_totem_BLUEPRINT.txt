WARDING TOTEM — editable textures (all 16x16 PNG, RGBA)
======================================================
A magic amethyst obelisk infused with cursed power. Model: models/block/warding_totem.json.
Shape, bottom to top (all within Minecraft's blocky style, ~1.6 blocks tall):
  - a tiered BLACKSTONE plinth        (12x12 y0-2, 10x10 y2-4)
  - a carved DEEPSLATE shaft          (8x8 y4-5 foot, 6x6 y5-8)
  - a RAGGED AMETHYST core band       (6x6 y8-13) that bleeds messily into the stone (warding_totem_core.png)
  - the deepslate shaft continues to a platform (6x6 y13-15)
  - a symmetric AMETHYST spike CROWN: a central pointed spire + four outward-leaning spikes, with slight
    height imperfections (crude, not machine-perfect)

⚠ Every face has an EXPLICIT in-[0,16] UV — the crown rises above y16, where auto-UV corrupts (brown specks /
transparent gaps). If you resize any crown element, keep its UV within 0..16 and matched to its pixel size.
Textures are uniform tiles (any 1:1 slice reads right), so just paint each 16x16 normally.

FILES (edit freely; F3+T reloads):
  warding_totem_blackstone.png   the plinth — near-black carved blackstone (a few amethyst flecks by default)
  warding_totem_deepslate.png    the shaft  — grey-blue deepslate
  warding_totem_gem.png          the crown spikes — a full-tile crystalline amethyst (any 1:1 slice reads as gem)
  warding_totem_core.png         the mid-shaft band — amethyst emerging RAGGEDLY from deepslate-grey (rows ~4-8),
                                   so its edges blend into the stone; paint the ragged silhouette here
  warding_totem_gem_off.png / warding_totem_core_off.png   the DEAD/grey versions shown when the totem is
                                   right-clicked OFF (disabled model swaps #gem + #core to these)

The block breathes purple magic particles from the core band + the crown (WardingTotemBlock.animateTick),
and flares a force-field dome whenever it blocks a spell — those are code, not textures.
