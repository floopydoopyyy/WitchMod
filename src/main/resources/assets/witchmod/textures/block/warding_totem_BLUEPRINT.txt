WARDING TOTEM — TEXTURE BLUEPRINT
=================================

The Warding Totem is the block that repels curses/blessings inside its radius, so it wants to read as a
deliberate, ornate protective monument — NOT just another decorated stone block. The MODEL is already a
custom shape (a stacked, tapering pillar): a wide plinth, a two-stage shaft, a flared collar, and a small
crowning gem. See models/block/warding_totem.json.

The model paints each part from a NAMED texture slot. Right now those slots point at vanilla textures so it
renders immediately. To give it bespoke art, make the PNGs below (16x16 each, standard block resolution) in
THIS folder (assets/witchmod/textures/block/) and repoint each slot in the model's "textures" block from the
"minecraft:block/..." value to "witchmod:block/warding_totem_<part>".

SLOTS  (model "textures" key  ->  suggested file)
-------------------------------------------------
  plinth      -> warding_totem_plinth.png       the wide base ring; heavy, grounded, carved stone
  plinth_top  -> warding_totem_plinth_top.png   top/bottom faces of the plinth (a flat capstone look)
  shaft       -> warding_totem_shaft.png        the two tapering column stages; vertical fluting/runes
  collar      -> warding_totem_collar.png        the flared band near the top; the "band of power" detail
  gem         -> warding_totem_gem.png           the crowning gem cube; make it glow-y / amethyst-like

LAYOUT NOTES
------------
- 16x16 per file. The shaft is used on its side faces only, so design it to TILE VERTICALLY (top edge should
  meet bottom edge) — the lower and upper shaft stages stack, so a seamless vertical repeat looks best.
- The plinth wraps a 14-wide ring; keep its detail horizontal (a carved base moulding) so it reads at a
  glance from across the room.
- The collar is only 2px tall on-screen, so keep it BOLD and simple — one strong horizontal motif (studs,
  a rune line, a metal band). Fine detail is lost at that height.
- The gem is the focal point. Consider an emissive-looking bright core (light purples/whites). If you later
  want it to actually emit light, that's a block light-level change in WardingTotemBlock, not a texture one.
- Palette suggestion to distinguish it from ordinary builds: cold carved stone (greys/deep blue-greys) for
  the plinth+shaft, a darker metal band for the collar, and a single saturated accent (amethyst purple) on
  the gem so the eye goes straight to the "charged" top.

OPTIONAL — more parts
---------------------
If you want finer control, split a slot into more elements in the model (e.g. a separate "shaft_top" band)
and add a matching texture slot. The model is plain JSON element cubes, so adding a carved ring or feet is
just another element + (optionally) another named slot here.
